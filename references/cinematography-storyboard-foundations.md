# 基础影视摄影与分镜

本参考用于所有需要文字分镜、导演阐述或视频生成提示词的项目。它补足通用的摄影指导和分镜基础，不针对赛车、汽车或某一类设备。

## 一、先决定镜头要完成什么

每个镜头先写一个可验证的任务，只能从以下几类中选择一至两项：

- 建立空间：让观众知道人物在哪里、方向是什么、人与物的距离如何。
- 交代人物：让观众读取身份、状态、关系或反应。
- 展示动作：让观众看清动作的起点、过程和落点。
- 提供信息：揭示道具、产品、线索或结果。
- 制造感受：通过距离、遮挡、光线、运动或时间让观众感到压迫、亲密、速度或停顿。
- 完成承接：把上一个镜头的动作、视线、形状、声音或空间方向交给下一个镜头。

如果一个镜头没有明确任务，不用用更多摄影形容词补救，应删除、合并或改写。

## 二、景别不是装饰，而是观看距离

- **大全景/远景**：建立人物与环境的关系、路线和规模；不能承担细腻表演。
- **全景**：读取完整身体动作、人物站位和移动路径；适合确认动作是否完成。
- **中景**：人物与手部动作、道具和环境保持关系；是叙事动作的常用景别。
- **中近景/近景**：读取表情、视线、压力和反应；背景信息被压缩。
- **特写**：只展示一个决定性细节。必须说明这个细节为何此刻重要。
- **极近特写**：只用于材质、触碰、微小变化或极端心理压力；使用后要尽快回到可读的空间或人物景别。

景别变化必须改变观众的理解或感受。连续使用相近景别，除非动作或表演本身在持续推进，否则不构成节奏。

## 三、焦段感、机位和构图

焦段首先描述透视关系，不是必须交给模型的精确镜头参数：

- **广角感**：前后景距离被拉开，空间和运动更强，人物靠近镜头时变形风险更高。
- **标准感**：人物比例自然，适合观察表演和现实空间关系。
- **长焦感**：前后景被压缩，适合观察距离、逼近、等待或把背景推近主体。

分镜必须同时说明：

1. 摄影机相对主体的方位和高度。
2. 主体位于画面左、中、右哪个区域，以及为什么留出负空间。
3. 前景、中景、背景各有什么信息。
4. 视线方向和运动方向是否留有空间。
5. 焦点从谁移向谁，焦点变化带来什么信息。

不要只写“电影感构图”“高级低机位”。应写成“摄影机位于人物侧后方，前景保留门框遮挡，人物向右侧门口看，画面右侧留出尚未打开的空间，观众先感到等待，再看到门外发生的事”。

## 四、摄影机运动必须有动机

- **固定**：让观众观察、等待、确认或感到压抑；画面内部动作承担推进。
- **推近**：增加关注、压力或亲密，不等于“情绪升级”四个字；需说明推近看见了什么。
- **拉远**：揭示空间、孤独、关系变化或结果。
- **横移/跟拍**：保持主体与空间关系，交代路径或陪伴动作。
- **摇摄/俯仰**：把观众视线从一个信息点引到另一个信息点；不能只为炫技。
- **环绕**：只有当主体关系、空间揭示或状态变化需要重新定位时使用。
- **手持/不稳定**：表现身体、现场或主观不确定性；不能把所有紧张都写成晃动。

写运镜时必须给出开始状态、运动目标和结束状态：摄影机从哪里开始，看向谁或什么，怎样移动，最后停在哪里。不要只写“镜头跟随人物移动”。

## 五、光线设计的五个问题

每一段至少回答：

1. 光源来自哪里，是画面内可见光源还是画外光源？
2. 光线从哪个方向打到主体，形成哪一侧明、哪一侧暗？
3. 光是硬、软、直射、漫射还是反射？
4. 背景与主体如何分离，画面哪里最亮、哪里最暗？
5. 光线在段落之间怎样变化，变化是否有剧情原因？

光线不要只写“冷色”“暖色”。例如：“顶部实用荧光灯形成硬质冷光，眼窝和下颌压暗；门打开后，门外较大的清晨漫射光从右后方进入，人物轮廓变亮，空间从封闭转为开放。”

色彩、对比度和光线方向必须服务于空间和情绪，不能用色温变化代替叙事变化。意识、记忆或主观段落也应通过可解释的光源、曝光、反差或运动规则区别，而不是默认加雾、发光或粒子。

## 六、人物调度、轴线和动作连续

- 先确定人物、摄影机和目标物的相对位置，再决定机位。
- 180 度轴线以内切换机位，保持人物视线和运动方向稳定；跨轴时必须有转向、过渡镜头或重新建立空间的理由。
- 动作切点要接动作末态：手正在抬起，下一镜接住抬起后的状态；不要让动作在无依据的位置跳变。
- 视线切必须有被看对象、反应或空间证据；不要用“看向远方”代替关系。
- 同一段动作要记录开始状态、关键变化和结束状态，包括手持物、门窗、身体朝向和道具位置。
- 快切可以省略过程，但相邻镜头仍要保留方向、力度或声音上的承接。

## 七、转场和剪辑节奏

转场先选择承接机制，再选择形式：

- **动作匹配**：相同或相反动作在两个空间接上。
- **视线匹配**：人物看向画外，下一镜展示被看对象。
- **形状匹配**：形状相似，但必须带来信息或意义变化。
- **声音桥**：下一空间的声音先进入，或上一空间的声音继续覆盖。
- **遮挡转场**：门、身体、物体或黑场暂时遮满画面，完成有根据的空间切换。
- **尺度切换**：特写切远景或远景切特写，改变观众理解的尺度。

每次转场都要写明：前一镜结束状态、切点、后一镜开始状态，以及转场让观众获得什么。不能把“意识流转场”当作承接理由本身。

节奏由镜头长度、动作密度、停顿和声音共同形成。快切段必须保留一至两个可读停顿；长镜头必须有画面内部变化。不要把每个音效都机械卡在剪辑点上，允许声音跨镜制造提前、延迟或反差。

## 八、分镜表的最低专业字段

每镜至少包含：

| 字段 | 必须回答的问题 |
|---|---|
| 时间与时长 | 观众看多久，是否足够看清动作或表情？ |
| 镜头任务 | 本镜新增什么信息、情绪或证据？ |
| 景别与焦段感 | 观众离主体多远，空间被拉开还是压缩？ |
| 机位与构图 | 摄影机在哪里，主体和前中后景如何安排？ |
| 光线与色彩 | 光源、方向、硬软、明暗和连续性是什么？ |
| 人物/物体动作 | 谁先动，动作经过什么变化，停在哪里？ |
| 摄影机运动 | 从哪里开始，朝什么运动，在哪里结束？ |
| 声音 | 环境声、动作声、音乐、对白和声音桥怎样工作？ |
| 切点与承接 | 为什么在这里切，下一镜接住什么？ |
| 叙事作用 | 观众此刻发现、期待、误判或确认什么？ |

## 九、交付前播放检查

在交付文字分镜前，按顺序默播整片：

1. 不看解释，只看镜头描述，能否知道人物在哪里、面向哪里、要去哪里？
2. 每个动作是否有起点、过程和落点？
3. 相邻镜头是否保持视线、方向、道具状态和光线逻辑？
4. 景别和运镜是否真的改变观看关系，而不是重复包装？
5. 每次转场是否有具体承接，而不是只写“自然切换”？
6. 画面关掉声音后，必需的行动和空间是否仍然可理解？
7. 声音关掉画面后，声音是否仍在推进时间、空间或情绪？
8. 最重要的画面是否得到足够时长，结尾是否兑现开头建立的期待？

没有实际生成或拍摄结果时，只能完成文本层面的检查，不能声称摄影效果已经验证。

## 十、镜头覆盖与可剪辑性

分镜不是漂亮镜头的集合，而是可以被剪辑成一场完整动作的覆盖设计。每个段落先确定一个主镜头，再决定需要哪些补充镜头：

- **建立镜头**：说明人物、空间、方向和行动目标；通常在空间发生变化或观众失去方位时使用。
- **主动作镜头**：完整保留动作的开始、变化和结束，是剪辑的骨架。
- **反应镜头**：展示人物接收信息后的变化，不要把反应当作无内容的表情插入。
- **关系镜头/过肩镜头**：说明人物与目标、对手、物体或空间的关系。
- **插入镜头**：提供一个必要细节，例如手、道具、屏幕或动作证据；必须能回到主动作。
- **结果镜头**：确认动作造成的结果，避免动作只完成了一半。

设计覆盖时先问：如果删掉这个镜头，观众会失去什么？如果答案只是“画面更丰富”，它通常不是必要覆盖。

一个动作段至少记录：主镜头的完整动作、一个能读取动机的反应或视线、一个必要的细节证据，以及动作结果。快切可以省略过程，但不能同时省略方向、动机和结果。

## 十一、场面调度

先安排人物和物体，再安排摄影机。每个段落写清楚：

1. 人物的起始位置、目标位置和移动路线。
2. 目标物或对手的位置，以及人物为什么向它移动。
3. 谁先动、谁等待、谁改变了空间关系。
4. 前景遮挡、中景主体和背景信息如何分层。
5. 人物停在哪里，停下后观众要看见什么。

人物移动不等于场面调度。场面调度要让位置变化带来关系变化，例如人物从门内走到门外，意味着从封闭空间进入公共空间；人物从背景走到前景，意味着信息或压力正在逼近。

如果场景中有门、窗、镜子、走廊、桌面或墙体，要说明它们是遮挡、分隔、反射、引导路线，还是制造前后景层次。不要让场景只作为背景纹理存在。

## 十二、光学、曝光与景深

摄影描述至少要区分四件事：透视、曝光、焦点和运动记录。

- **透视**由摄影机位置和焦段感共同决定。改变摄影机距离会改变人物与背景的空间关系，不能只靠“换焦段”解决。
- **曝光**决定观众能否读取暗部、亮部和材质。高反差必须有原因，不能让关键信息落入无意义的黑或白。
- **焦点**决定观众此刻看谁。焦点转移必须有明确目标，并说明转移前后新增的信息。
- **景深**决定空间是被压平、分离还是同时可读。浅景深不能自动等于高级；需要表演、道具或空间关系同时清楚时，应保留足够景深。
- **运动记录**由运动速度、快门感和摄影机稳定性共同产生。速度感不能只依靠过度模糊、数字拉伸或镜头抖动。

写“浅景深”“慢动作”“运动模糊”时，必须说明它解决什么观看问题：是隔离人物、延长关键动作、强调重量，还是隐藏空间信息。若没有功能，删除该效果。

## 十三、光线连续性与场景照明

每个场景先建立一套照明规则，再在镜头内变化：

- 主光源在空间中的位置固定，除非剧情明确改变光源。
- 人物移动时，光线变化应来自人物靠近或离开光源，而不是每个镜头重新换光。
- 画内灯具、窗户和门外光线要与人物脸部和地面阴影方向一致。
- 背景亮度、主体轮廓和负补光共同决定层次；不要用统一提亮代替分层。
- 场景从室内到室外时，先决定曝光适应和色彩关系，再决定是否需要明显反差。
- 主观段落可以改变反差、色彩或光源可见性，但必须建立规则并在后续兑现。

光线设计应写成可拍摄的因果：“门打开后，门外较大的漫射光从人物右后方进入，人物轮廓被勾亮，室内冷光仍保留在脸部左侧”，而不是“更加高级、更有电影感”。

## 十四、表演与镜头距离

表演要按景别拆解，而不是只写情绪形容词：

- 远景用姿态、速度、停顿和路线表达状态。
- 中景用手部、肩颈、身体朝向和与物体的关系表达行动。
- 近景用眼神落点、呼吸、下颌、嘴角和微小停顿表达心理变化。
- 特写只保留一个决定性动作或反应，不要同时要求复杂表演和复杂摄影运动。

每个表演动作写明刺激、反应和落点：人物先听见什么或看见什么，身体先出现什么变化，最后停在哪里。克制表演不是“没有动作”，而是动作幅度小但因果清楚。

## 十五、声音与画面的叙事分工

声音分为四个层级：

1. **空间底噪**：证明人物所在的环境。
2. **动作声**：证明动作真的发生，并帮助剪辑接点。
3. **主观声**：表达人物听觉、记忆、压力或注意力变化。
4. **音乐与语言**：组织段落节奏、观点和品牌意义。

每个关键声音要说明它是画内声还是画外声、何时进入、何时结束，以及是否跨镜。声音可以先于画面制造期待，也可以在画面结束后留下结果，但不能让所有声音都同时争夺注意力。

画面和声音不要重复同一信息。若画面已经清楚展示动作，声音可以提供重量、距离或心理变化；若声音承担空间信息，画面要提供足够的反应或证据。

## 十六、分镜从文字到可视化

交付文字分镜时，先为每镜写一条“观众看到的连续句子”，再写技术信息。例如：

“车手从门内走到门外，门板遮住镜头，门板移开时他已经进入维修区。”

然后补充景别、机位、光线、运镜和切点。不要先堆焦段和器材，再让观众猜发生了什么。

每个段落应至少有一个可记住的画面内部关系：人物与门、人物与光、人物与道具、前景与背景、静止与运动，或局部与整体。没有画面内部关系的分镜，通常只是镜头目录。

## 十七、补强后的自审顺序

交付前按以下顺序检查，不要先检查风格词：

1. 观众是否知道主体、空间、目标和方向？
2. 主动作是否有动机、过程和结果？
3. 覆盖是否足以剪出完整动作，而不是只有特写素材？
4. 摄影机运动是否由信息、关系或身体感驱动？
5. 景别、焦段感和景深是否改变观看关系？
6. 光源、曝光、阴影和色彩是否在相邻镜头中连续？
7. 人物调度是否真的改变了空间关系？
8. 声音是否提供了画面没有的空间或心理信息？
9. 每次切镜是否接住动作、视线、声音、形状或结果？
10. 删除所有风格形容词后，画面是否仍然可以被拍摄和剪辑？
